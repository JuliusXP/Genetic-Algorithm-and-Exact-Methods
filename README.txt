The project compares Genetic Algorithms against exact recursive methods and Dynamic Programming for solving several combinatorial optimization problems. 
The implemented optimization problems include Subset Sum, Partition Problem, Bin Packing, and Multi-dimensional Knapsack.
It provides a configurable Genetic Algorithm framework where different parameters such as population size, selection method, crossover rate, mutation rate, elitism, and number of generations can be modified to evaluate their impact on solution quality, execution time, and memory usage.
